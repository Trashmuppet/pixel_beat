# UI Bible

## Philosophy
The interface should disappear behind creativity. Every control must either help users create a beat faster or improve the exported animation.

## Platform
- Android 16 (API 36)
- Jetpack Compose
- Material 3

## Navigation
1. Home
2. Project
3. Sequencer
4. Arrangement
5. Export
6. Settings

## Layout
- Large touch targets (48dp minimum)
- Single primary action per screen
- Sparse controls
- No hidden gestures for essential actions

## Colour
- Background: Black
- Foreground: White
- Accent: Reserved for system status only

## States
Loading, Empty, Editing, Playing, Exporting, Error, Success

## Accessibility
- Screen-reader labels
- High contrast
- Haptic feedback
- Scalable text where appropriate
